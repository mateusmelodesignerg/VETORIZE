# VETORIZE

Um prompt gratuito da Layer Web. Cole na sua ferramenta de IA e receba em um único arquivo index.html, sem framework e sem etapa de build.

Como usar
Abra o VETORIZE.md e copie todo o conteúdo.
Cole como uma única mensagem no Claude Code, Cursor, Lovable ou V0.
Abra o index.html gerado no navegador.
Troque pelo seu texto, suas cores e sua imagem, mantendo a estrutura.

Dica: ajuste uma seção por vez. Pedir uma reescrita completa pode sobrescrever o que você já acertou.

O que tem dentro
Animação de entrada, layout responsivo e noções básicas de acessibilidade
Medidas, cores e tempos de animação exatos, para o resultado ficar igual ao original
